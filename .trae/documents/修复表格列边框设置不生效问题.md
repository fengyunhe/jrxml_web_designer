## 问题分析

通过对代码的分析，我发现表格列边框设置不生效的原因是：

1. **属性存储位置不一致**：在ElementProperties.vue中，表格列的边框设置直接存储在单元格对象的根级别属性中（如`column.columnHeader.borderStyle`）
2. **生成逻辑不匹配**：在jrxmlGenerator.ts中，generateBoxXML函数只处理元素的`box`属性，而不处理根级别上的边框属性
3. **解析逻辑不匹配**：在parse.ts中，parseBoxElement函数将边框属性解析到`element.box`对象中，但表格UI直接从元素根级别读取边框属性

## 解决方案

### 1. 修改generateBoxXML函数

在`jrxmlGenerator.ts`中修改`generateBoxXML`函数，使其能够处理直接存储在元素对象根级别的边框属性，作为向后兼容的处理：

```typescript
// 生成box元素XML
function generateBoxXML(box: any, element: any): string {
  // 如果没有box对象，创建一个临时对象
  const boxData = box || {};
  
  // 检查直接存储在元素根级别的边框属性（向后兼容）
  if (element && !boxData.pen && (element.borderWidth || element.borderStyle || element.borderColor)) {
    boxData.pen = {
      lineWidth: element.borderWidth,
      lineStyle: element.borderStyle,
      lineColor: element.borderColor
    };
  }
  
  // 剩余逻辑保持不变
  // ...
}
```

### 2. 修改generateElementXML函数

在调用`generateBoxXML`时传入元素对象，以便`generateBoxXML`函数能够访问元素根级别的边框属性：

```typescript
// 生成静态文本XML
function generateStaticTextXML(element: any): string {
  // ...
  // 生成box元素，传入element对象
  xml += generateBoxXML(element.box, element);
  // ...
}

// 生成动态文本XML
function generateTextFieldXML(element: any): string {
  // ...
  // 生成box元素，传入element对象
  xml += generateBoxXML(element.box, element);
  // ...
}
```

### 3. 修改parseElement函数

在`parse.ts`中修改`parseElement`函数，确保解析到的边框属性同时存储在元素的根级别，以便表格UI能够正确显示：

```typescript
function parseElement(element: Element, type: string): any {
  // ...
  // 查找box元素，考虑命名空间
  const boxElement = findChildElement(element, 'box');
  if (boxElement) {
    result.box = parseBoxElement(boxElement);
    
    // 将边框属性复制到元素根级别，以便表格UI能够正确显示
    if (result.box.pen) {
      result.borderWidth = result.box.pen.lineWidth;
      result.borderStyle = result.box.pen.lineStyle;
      result.borderColor = result.box.pen.lineColor;
    }
  }
  // ...
}
```

### 4. 修改getCellStyle函数

在`TableElement.vue`中修改`getCellStyle`函数，使其能够从`element.box`对象中获取边框属性，作为优先选项：

```typescript
// 获取单元格样式
function getCellStyle(cell: any) {
  // ...
  // 边框样式 - 优先从box对象获取，否则从根级别获取
  let borderWidth = 0;
  let borderStyle = 'solid';
  let borderColor = '#000000';
  
  if (cell.box && cell.box.pen) {
    borderWidth = cell.box.pen.lineWidth || 0;
    borderStyle = cell.box.pen.lineStyle || 'solid';
    borderColor = cell.box.pen.lineColor || '#000000';
  } else {
    borderWidth = cell.borderWidth || 0;
    borderStyle = cell.borderStyle || 'solid';
    borderColor = cell.borderColor || '#000000';
  }
  
  if (borderWidth > 0) {
    styles.border = `${borderWidth}px ${borderStyle} ${borderColor}`;
  }
  // ...
}
```

## 预期效果

1. 当用户在表格属性面板中设置列边框时，边框设置会同时存储在元素的根级别和`element.box`对象中
2. 生成JRXML时，边框属性会被正确地包含在`<box>`元素中
3. 解析JRXML时，边框属性会被正确地存储到元素的根级别和`element.box`对象中
4. 表格UI会正确地显示边框样式

## 注意事项

1. 确保修改后的代码保持向后兼容性，不会破坏现有功能
2. 确保生成的JRXML符合XSD规范
3. 确保解析和生成的逻辑保持一致
